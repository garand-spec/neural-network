# normalization_learning

用于学习数据归一化、计算机视觉和 PyTorch 基础模型的练习项目。

目录说明见 [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md)。

## 环境

```powershell
python -m pip install -r requirements.txt
```

部分训练脚本还需要 PyTorch、torchvision、OpenCV 和 tqdm；请按所运行的示例安装。

## 快速运行

```powershell
python examples/normalization/demo.py
python -m projects.cnn_classifier.scripts.smoke_test
```
